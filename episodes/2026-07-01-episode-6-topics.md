## AWS Invests $1 Billion in "Forward Deployed Engineering" AI Unit

AWS announced a $1 billion investment to create a new "Forward Deployed Engineering" (FDE) unit. This unit will embed "thousands" of engineers—alongside AI agents—directly into customers' businesses to help them build and deploy AI systems rapidly.

**Key Takeaways:**
- **The FDE Model:** Forward Deployed Engineers are embedded directly within a different business to accelerate tech transformations (a concept originally popularized by Palantir).
- **Speed is the Currency:** AWS VP Francessca Vasquez noted that "speed" is what customers care about most right now. AWS embeds pods of 5-6 engineers for a few weeks to leave behind self-sufficient teams with new AI solutions.
- **Following the Trend:** Anthropic and OpenAI both launched similar FDE initiatives earlier this year (Anthropic with Blackstone/Goldman Sachs, and OpenAI with TPG/Bain Capital).
- **Targeting Regulated Industries:** AWS anticipates the next major wave of AI adopters will be companies in highly regulated industries with diverse datasets.

## Bora Agentic Brand Shorts

### Building a Company Brain

When people say "company brain," they usually jump too quickly to the database or vector store. The better question is: what kind of work do you want your agents to do? If the agent needs to answer questions from docs, briefs, SOPs, and past decisions, you need a knowledge layer. If it needs to run reports, compare campaigns, or calculate ROI, you need structured data. If it needs to take action, it needs tools and permissions through something like MCP. A company brain is not one backend. It is the combination of knowledge, structured data, tools, permissions, and memory that lets agents do useful work without guessing.

### ROI of Agentic Transformation

CEOs should not measure agentic transformation by how many people are "using AI." Measure the workflow before and after. Did the team produce more usable creative? Did influencer outreach get faster? Did the number of tested Meta ad variants go up? Did review cycles shrink? Did CAC, ROAS, or product revenue move? Did manual hours drop without quality dropping? The unit of ROI is not the prompt. It is the repeated workflow. If an agent saves time, increases output, improves quality, or helps revenue-producing work happen faster, then you can measure it.

### High-Impact Agentic Workflows

The best place for DTC brands to start is usually where there is high volume and a clear revenue connection. Influencer campaigns and media asset generation are perfect examples. Agents can help find creators, score fit, organize outreach, generate briefs, process creator content, create ad variants, resize assets, write hooks, and feed performance data back into the next batch. The point is not "AI made an image." The point is building a system where creator content turns into more tested ads, faster, with less manual coordination.

### Where to Start with AI Agents

A company should start with the work that is already repetitive. Not the coolest use case. Not the biggest abstract strategy deck. Look for something the team does dozens or hundreds of times a month: reviewing creators, making ad variants, tagging assets, writing briefs, pulling reports, checking performance, or answering the same operational questions. If it happens once, use ChatGPT or Claude manually. If it keeps happening, that is agent territory. The first agent should be boring, useful, measurable, and easy for the team to inspect and improve.
